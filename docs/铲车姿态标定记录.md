## 可直接用于部署的参数

完整姿态行，顺序为 `servo1,servo2,servo3,servo4,servo5,gripper`：

```text
l_shape_push_pose=518,196,176,597,500,335
```

PowerShell 入口可传：

```powershell
-LShapePushPose '518,196,176,597,500,335'
```

如果部署时仍希望保持“放置后先松爪，再切铲车姿态推进”，可以继续传：

```powershell
-LShapePushReleaseBefore true
```

注意：当前代码还有 `l_shape_push_gripper_position` 覆盖通道。若要完整复现这次记录的夹爪 pulse=335，需要同时传：

```powershell
-LShapePushGripperPosition -1
```

若希望推块时夹爪保持更打开的铲车状态，则保留当前默认：

```powershell
-LShapePushGripperPosition 200
```
