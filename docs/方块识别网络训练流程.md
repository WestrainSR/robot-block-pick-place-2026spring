# 方块识别网络训练流程

目标：训练四类磁吸方块检测模型，并导出为机器人 `yolov11_detect` 节点可直接加载的 OpenVINO 文件：

```text
competition_blocks.xml
competition_blocks.bin
```

类别顺序必须固定为：

```text
0 redstone
1 glass
2 glowstone
3 grass
```

## 1. 数据采集

采集脚本已经加入 ROS2 包：

```text
competition_pick_place/competition_pick_place/capture_dataset.py
```

在机器人 Docker 容器 `MentorPi` 中构建后即可运行：

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
colcon build --symlink-install --packages-select competition_pick_place
source install/setup.bash
```

启动相机/底层硬件后，分场景采集。示例：

```bash
ros2 run competition_pick_place capture_dataset --ros-args \
  -p class_name:=redstone \
  -p scene_name:=front_close \
  -p count:=120 \
  -p interval:=0.25 \
  -p output_dir:=/home/ubuntu/datasets/block_dataset/raw
```

四类都采：

```bash
for cls in redstone glass glowstone grass; do
  ros2 run competition_pick_place capture_dataset --ros-args \
    -p class_name:=$cls \
    -p scene_name:=single_block \
    -p count:=150 \
    -p interval:=0.25 \
    -p output_dir:=/home/ubuntu/datasets/block_dataset/raw
done
```

也要采“四类同时出现”的图，用来训练模型从多个候选中找到目标：

```bash
ros2 run competition_pick_place capture_dataset --ros-args \
  -p class_name:=mixed \
  -p scene_name:=all_blocks_material_area \
  -p count:=250 \
  -p interval:=0.20 \
  -p output_dir:=/home/ubuntu/datasets/block_dataset/raw
```

建议采集量：

- 每类单独出现：每类 150-250 张
- 四类同时出现：300-500 张
- 背景/无目标：80-150 张，`class_name:=background`
- 不同距离、角度、光照、遮挡、手刚移开的瞬间都要覆盖

采集输出示例：

```text
/home/ubuntu/datasets/block_dataset/raw/
  redstone/single_block_20260514_153000/*.jpg
  glass/single_block_20260514_153300/*.jpg
  mixed/all_blocks_material_area_20260514_154000/*.jpg
```

## 2. 拷回训练电脑

机器人热点会断互联网，所以建议采完后用 WinSCP/SFTP 或 `scp` 拉回本机：

```bash
scp -r pi@192.168.149.1:/home/ubuntu/datasets/block_dataset/raw ./datasets/block_dataset/raw
```

如果 `/home/ubuntu` 在 Docker 内，优先用 WinSCP 从共享目录转出，或者先在机器人上执行 `docker cp`。

## 3. 标注

推荐用支持 YOLO 格式的工具，例如 LabelImg、CVAT、Roboflow、本地 label-studio。导出格式必须是 YOLO txt：

```text
class_id x_center y_center width height
```

坐标必须归一化到 0-1。

标注要求：

- 框贴紧方块外边缘，不要把大面积背景框进去。
- 四类同时出现时，每个方块都要标。
- 类别 id 必须严格对应：
  - `0 redstone`
  - `1 glass`
  - `2 glowstone`
  - `3 grass`
- 背景图可以没有标签文件，或保留空 txt。

整理成临时标注目录：

```text
datasets/block_dataset/labeled/
  images/
    xxx.jpg
  labels/
    xxx.txt
```

## 4. 生成 YOLO 数据集

本仓库提供数据集整理脚本：

```text
tools/prepare_yolo_dataset.py
```

运行：

```bash
python tools/prepare_yolo_dataset.py \
  --images datasets/block_dataset/labeled/images \
  --labels datasets/block_dataset/labeled/labels \
  --out datasets/block_dataset/yolo \
  --train 0.8 \
  --val 0.1 \
  --test 0.1 \
  --copy-empty
```

输出：

```text
datasets/block_dataset/yolo/
  images/train
  images/val
  images/test
  labels/train
  labels/val
  labels/test
  data.yaml
```

## 5. 训练

建议先用轻量模型，便于机器人实时推理：

```bash
yolo detect train \
  model=yolo11n.pt \
  data=datasets/block_dataset/yolo/data.yaml \
  epochs=120 \
  imgsz=640 \
  batch=16 \
  patience=30 \
  project=runs/block_detection \
  name=competition_blocks_yolo11n
```

训练完成后重点检查：

```text
runs/block_detection/competition_blocks_yolo11n/results.png
runs/block_detection/competition_blocks_yolo11n/confusion_matrix.png
runs/block_detection/competition_blocks_yolo11n/weights/best.pt
```

如果某类经常混淆，先补数据和修标注，不要急着调复杂参数。

## 6. 本地预测检查

```bash
yolo detect predict \
  model=runs/block_detection/competition_blocks_yolo11n/weights/best.pt \
  source=datasets/block_dataset/yolo/images/test \
  imgsz=640 \
  conf=0.5 \
  save=True
```

验收标准：

- 四类同时出现时能全部框出。
- 置信度通常大于 0.70。
- 不把场地纹理、手、夹爪误检成方块。

## 7. 导出 OpenVINO

机器人当前 `yolov11_detect` 节点加载的是 OpenVINO `.xml` 模型。导出：

```bash
yolo export \
  model=runs/block_detection/competition_blocks_yolo11n/weights/best.pt \
  format=openvino \
  imgsz=640
```

导出目录一般类似：

```text
runs/block_detection/competition_blocks_yolo11n/weights/best_openvino_model/
```

把里面的模型文件改名为：

```text
competition_blocks.xml
competition_blocks.bin
```

## 8. 部署到机器人

上传到容器内：

```text
/home/ubuntu/ros2_ws/src/yolov11_detect/models/competition_blocks.xml
/home/ubuntu/ros2_ws/src/yolov11_detect/models/competition_blocks.bin
```

然后单独验证 YOLO：

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash

ros2 launch competition_pick_place competition_run.launch.py \
  dry_run:=true \
  start_yolo:=true \
  start_camera:=true \
  yolo_model:=competition_blocks \
  target_class:=grass
```

另开终端查看检测结果：

```bash
ros2 topic echo /yolo_node/object_detect
```

确认输出中 `class_name` 是 `redstone/glass/glowstone/grass`，再进入闭环实跑。

## 9. 常见问题

### 机器人采集不到图

检查相机 topic：

```bash
ros2 topic list | grep image
ros2 topic hz /ascamera/camera_publisher/rgb0/image
```

如果没有 `/ascamera/camera_publisher/rgb0/image`，先启动原厂底层/相机 launch。

### 训练效果看起来很好，机器人上很差

通常是数据分布不一致。补采：

- 比赛场地真实光照
- 机器人真实视角
- 四个方块同时出现在原料区
- 夹爪、桌面边缘、色环、阴影等干扰

### 类别全错位

检查 `data.yaml` 和机器人 launch 中的类别顺序是否完全一致：

```text
redstone, glass, glowstone, grass
```
