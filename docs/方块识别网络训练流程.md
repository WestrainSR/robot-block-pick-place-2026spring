# 红绿蓝方块识别网络训练流程

目标：训练红、绿、蓝三类方块检测模型，并导出为机器人 `yolov11_detect` 节点可直接加载的 OpenVINO 文件：

```text
competition_blocks.xml
competition_blocks.bin
```

类别顺序必须固定为：

```text
0 red
1 green
2 blue
```

## 1. 本地 UI 采集

现在推荐用本地采集 UI。它会自动：

- 连接机器人热点
- 通过 SSH 进入机器人 Docker
- 订阅机器人 ROS 相机 topic
- 抓取当前帧
- 保存到本地 `datasets/color_block_capture`
- 维护 manifest 和每类缺口统计

启动：

```powershell
python tools/color_block_capture_ui.py --port 8765
```

浏览器打开：

```text
http://127.0.0.1:8765
```

人在采集时只需要：

1. 点击“连接机器人热点”
2. 点击“检测相机”
3. 按 UI 提示摆放红/绿/蓝方块
4. 点击“拍照并保存”

默认采集目标：

```text
每类总计 300 张有效样本
```

其中包括：

```text
单块正面中距           每类 50 张
距离变化               每类 50 张
角度变化               每类 50 张
光照和背景变化         每类 40 张
轻微遮挡/夹爪干扰      每类 30 张
红绿蓝三色同框         全局 80 张，同时计入三类
```

本地输出：

```text
datasets/color_block_capture/
  manifest.csv
  raw/
    red/
    green/
    blue/
    mixed/
```

## 2. 图片要求

### 单块正面中距

- 只放当前颜色方块。
- 方块完整入镜，位于画面中部。
- 方块占画面宽度约 15%-35%。
- 背景尽量接近比赛原料区。

### 距离变化

- 只放当前颜色方块。
- 近、中、远距离都要有。
- 图像清晰，不要运动模糊。
- 方块不能被裁切。

### 角度变化

- 只放当前颜色方块。
- 左前、右前、斜侧方向都要采。
- 可以看到侧面。
- 不要让方块贴边。

### 光照和背景变化

- 覆盖阴影、反光、偏暗、偏亮。
- 覆盖不同地面纹理。
- 避免严重过曝。

### 轻微遮挡/夹爪干扰

- 可以让夹爪边缘、手刚离开后的轻微遮挡入镜。
- 遮挡不要超过方块面积 20%。
- 方块主体颜色仍要清楚。

### 红绿蓝三色同框

- 三种颜色同时入镜。
- 每块都完整可见并彼此分开。
- 多换排列顺序、距离和角度。

## 3. 标注

推荐用支持 YOLO 格式的工具，例如 LabelImg、CVAT、Roboflow、本地 label-studio。导出格式必须是 YOLO txt：

```text
class_id x_center y_center width height
```

坐标必须归一化到 0-1。

类别 id 必须严格对应：

```text
0 red
1 green
2 blue
```

整理成：

```text
datasets/color_block_capture/labeled/
  images/
    xxx.jpg
  labels/
    xxx.txt
```

## 4. 生成 YOLO 数据集

运行：

```powershell
python tools/prepare_yolo_dataset.py `
  --images datasets/color_block_capture/labeled/images `
  --labels datasets/color_block_capture/labeled/labels `
  --out datasets/color_block_capture/yolo `
  --train 0.8 `
  --val 0.1 `
  --test 0.1 `
  --copy-empty
```

输出：

```text
datasets/color_block_capture/yolo/
  images/train
  images/val
  images/test
  labels/train
  labels/val
  labels/test
  data.yaml
```

## 5. 训练

建议先用轻量模型，便于机器人实时推理：

```bash
yolo detect train \
  model=yolo11n.pt \
  data=datasets/color_block_capture/yolo/data.yaml \
  epochs=120 \
  imgsz=640 \
  batch=16 \
  patience=30 \
  project=runs/block_detection \
  name=competition_blocks_yolo11n
```

训练完成后重点检查：

```text
runs/block_detection/competition_blocks_yolo11n/results.png
runs/block_detection/competition_blocks_yolo11n/confusion_matrix.png
runs/block_detection/competition_blocks_yolo11n/weights/best.pt
```

## 6. 本地预测检查

```bash
yolo detect predict \
  model=runs/block_detection/competition_blocks_yolo11n/weights/best.pt \
  source=datasets/color_block_capture/yolo/images/test \
  imgsz=640 \
  conf=0.5 \
  save=True
```

验收标准：

- 红绿蓝同时出现时能全部框出。
- 置信度通常大于 0.70。
- 不把场地纹理、手、夹爪误检成方块。

## 7. 导出 OpenVINO

机器人当前 `yolov11_detect` 节点加载的是 OpenVINO `.xml` 模型。导出：

```bash
yolo export \
  model=runs/block_detection/competition_blocks_yolo11n/weights/best.pt \
  format=openvino \
  imgsz=640
```

把导出的模型文件改名为：

```text
competition_blocks.xml
competition_blocks.bin
```

## 8. 部署到机器人

上传到容器内：

```text
/home/ubuntu/ros2_ws/src/yolov11_detect/models/competition_blocks.xml
/home/ubuntu/ros2_ws/src/yolov11_detect/models/competition_blocks.bin
```

然后单独验证 YOLO：

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash

ros2 launch competition_pick_place competition_run.launch.py \
  dry_run:=true \
  start_yolo:=true \
  start_camera:=true \
  yolo_model:=competition_blocks \
  target_class:=red
```

另开终端查看检测结果：

```bash
ros2 topic echo /yolo_node/object_detect
```

确认输出中 `class_name` 是 `red/green/blue`，再进入闭环实跑。
