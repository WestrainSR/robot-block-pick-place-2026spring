已完成过的机器人侧整理：

## 4. 控制链路

当前主流程：

```text
INIT
-> NAV_TO_MATERIAL
-> SEARCH_TARGET
-> ALIGN_TARGET
-> PICK
-> NAV_TO_PLACE
-> ALIGN_PLACE
-> PLACE
-> NAV_HOME
-> DONE
```

失败进入：

```text
FAILSAFE
```

当前抓取策略：

1. 等待 `/yolo_node/object_detect` 真正发布消息；
2. 根据目标类别筛选检测框；
3. 使用检测框中心误差控制左右；
4. 优先读取深度图 `/ascamera/camera_publisher/depth0/image_raw`，在目标框中心 ROI 中取中位数距离；
5. 深度无效时回退到检测框面积；
6. 进入预抓取阶段后，机械臂动作执行期间仍保持视觉伺服；
7. 低位不再等待视觉确认，直接闭合夹爪；
8. 通过 `/controller_manager/servo_states` 读取夹爪舵机位置判断是否夹到；
9. 抓取失败时重新对准并重试，默认最多 3 次。

关键默认参数：

```text
target_class=grass
yolo_model=tongji
yolo_classes=gray,yellow,grass,blue
use_depth_distance=true
pick_target_depth_m=0.32
pick_depth_tolerance_m=0.025
pick_target_area_ratio=0.043
control_mode=p
closed_loop_pick=false
pick_retry_attempts=3
gripper_servo_id=10
gripper_empty_close_position=500
gripper_grasp_min_gap=30
```

注意：直接 launch 的默认 `control_mode=p`、`closed_loop_pick=false` 偏保守；实机抓取脚本和 UI 会显式打开 `control_mode:=mpc`、`closed_loop_pick:=true`。

## 5. 推荐运行方式

### 5.1 无实时画面单次试验

推荐优先使用：

```powershell
python tools\headless_grasp_trial.py --target-class grass
```

可选目标：

```powershell
python tools\headless_grasp_trial.py --target-class gray
python tools\headless_grasp_trial.py --target-class yellow
python tools\headless_grasp_trial.py --target-class grass
python tools\headless_grasp_trial.py --target-class blue
```

调目标距离：

```powershell
python tools\headless_grasp_trial.py --target-class grass --target-depth 0.30
python tools\headless_grasp_trial.py --target-class grass --target-depth 0.34
```

结果包：

```text
runs/grasp_headless/*.tar.gz
```

### 5.2 本地 UI

```powershell
python tools\robot_yolo_control_ui.py --port 8090
```

打开：

```text
http://127.0.0.1:8090
```

UI 适合查看 YOLO 画面、调整参数、启动/停止抓取和检查机器人端进程数量。若网络或视频流不稳定，优先回到 headless 试验流程。

### 5.3 直接容器内 ROS2 命令

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash

ros2 launch competition_pick_place competition_run.launch.py \
  target_class:=grass \
  dry_run:=false \
  stop_after_pick:=true \
  exit_on_done:=true \
  start_navigation:=false \
  start_base:=false \
  start_camera:=false \
  start_yolo:=true \
  use_nav:=false \
  use_arm:=true \
  yolo_model:=tongji \
  yolo_classes:=gray,yellow,grass,blue \
  init_action:=navigation_pick_init_ai \
  pick_action:=navigation_pick_ai \
  control_mode:=mpc \
  closed_loop_pick:=true
```

## 6. 部署

部署 ROS2 包：

```powershell
python tools\deploy_competition_package_to_robot.py
```

部署当前 `tongji` 模型：

```powershell
python tools\deploy_openvino_to_robot.py `
  --local-dir model\best_openvino_model `
  --model-name tongji `
  --xml model\best_openvino_model\tongji.xml `
  --bin model\best_openvino_model\tongji.bin
```

如果使用旧红绿蓝模型：

```powershell
python tools\deploy_openvino_to_robot.py `
  --local-dir deployment\competition_blocks_openvino `
  --model-name competition_blocks
```

运行时也必须同步切换：

```text
yolo_model:=competition_blocks
yolo_classes:=red,green,blue
```
