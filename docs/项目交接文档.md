## 3. 新增 ROS2 包

入口：

```text
competition_pick_place/competition_pick_place/competition_node.py
competition_pick_place/launch/competition_run.launch.py
competition_pick_place/config/competition_waypoints.yaml
competition_pick_place/config/classes.yaml
```

状态机：

```text
INIT -> NAV_TO_MATERIAL -> SEARCH_TARGET -> ALIGN_TARGET -> PICK
     -> NAV_TO_PLACE -> ALIGN_PLACE -> PLACE -> NAV_HOME -> DONE
```

失败时进入：

```text
FAILSAFE
```

控制策略：

- 大范围运动：Nav2 `BasicNavigator`。
- 末端接近：订阅 `/yolo_node/object_detect`，按检测框中心误差和面积误差发布 `/controller/cmd_vel`。
- 抓取/放置：复用原厂动作组 `navigation_pick_init`、`navigation_pick`、`navigation_place`。
- 安全：搜索、对齐、导航均有超时；失败或停止时发布零速度。

## 5. 实跑前必须补齐

### 5.1 四类方块模型

机器人当前没有四类方块模型。需要训练或导出 OpenVINO 模型，并放到：

```text
/home/ubuntu/ros2_ws/src/yolov11_detect/models/competition_blocks.xml
/home/ubuntu/ros2_ws/src/yolov11_detect/models/competition_blocks.bin
```

类别顺序必须保持：

```text
redstone, glass, glowstone, grass
```

### 5.2 导航地图和坐标

当前机器人只有原厂 `map_01`、`map_02`，没有确认可用的 `competition_map`。需要现场建图或指定已有地图。

必须标定并写入：

```text
/home/ubuntu/ros2_ws/src/competition_pick_place/config/competition_waypoints.yaml
```

至少需要：

```yaml
material_standoff_pose:
  x: ...
  y: ...
  yaw: ...
place_standoff_pose:
  x: ...
  y: ...
  yaw: ...
return_pose:
  x: ...
  y: ...
  yaw: ...
```

代码中已有保护：真实运行且使用 Nav2 时，如果材料区或放置区仍为 `[0, 0]`，会直接失败保护，不会盲目出车。

## 6. 最终实跑命令

```bash
ros2 launch competition_pick_place competition_run.launch.py \
  target_class:=grass \
  dry_run:=false \
  start_navigation:=true \
  start_yolo:=true \
  yolo_model:=competition_blocks \
  map_name:=competition_map
```

如目标为其他方块，只替换 `target_class`。
