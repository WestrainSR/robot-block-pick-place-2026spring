## 目前实现的功能

1. 输入机器人摄像头 RGB 图像后，模型可以检测红、绿、蓝三种实体方块。
2. 每个检测结果包含类别名、置信度、方块 bounding box。
3. 当前闭环控制节点可以使用检测框中心进行左右对齐，使用检测框面积估计前后距离。
4. 模型已经导出为 OpenVINO 格式，适合接入机器人已有 `yolov11_detect` 推理节点。
5. 测试集上使用 `conf=0.70` 时，所有测试样本都能检出目标颜色。

## 当前边界和风险

1. 当前采集数据主要是单个方块，缺少红绿蓝同框、多目标互相遮挡的数据。
2. 蓝色类别的框精度弱于红色和绿色，测试中出现过同一蓝块被框两次的情况。
3. 当前评估基于本地采集测试集，还没有在机器人实时摄像头闭环运行中完成最终验收。
4. 如果赛场光照、地面反光、方块材质和当前数据差异较大，仍建议补采 20-50 张真实场景图片再增量训练。

## 复现命令

自动标注：

```powershell
python tools/auto_label_color_blocks.py
```

拆分 YOLO 数据集：

```powershell
python tools/prepare_yolo_dataset.py --images datasets/color_block_capture/auto_labeled/images --labels datasets/color_block_capture/auto_labeled/labels --out datasets/color_block_capture/yolo --train 0.8 --val 0.1 --test 0.1
```

训练：

```powershell
python tools/train_color_block_yolo.py --epochs 80 --batch 8 --workers 0 --exist-ok
```

可视化：

```powershell
python tools/visualize_color_block_model.py --conf 0.70
```

导出 OpenVINO：

```powershell
python -c "from ultralytics import YOLO; YOLO(r'runs/block_detection/competition_blocks_yolo11n/weights/best.pt').export(format='openvino', imgsz=640)"
```
