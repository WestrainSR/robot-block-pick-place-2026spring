# 无实时画面抓取调参流程

当前不再依赖本地 UI 的实时视频流。调参方式改成：机器人自主执行一次抓取，同时在机器人端保存关键帧、YOLO 框和日志；执行结束后自动拉回本地结果包。

## 运行一次

1. 电脑 WiFi 切到 `HW-9E5ACFD8`。
2. 方块放到机器人正前方。
3. 在本地运行：

```powershell
python tools\headless_grasp_trial.py --target-class grass
```

灰块：

```powershell
python tools\headless_grasp_trial.py --target-class gray
```

黄块/蓝块：

```powershell
python tools\headless_grasp_trial.py --target-class yellow
python tools\headless_grasp_trial.py --target-class blue
```

结果会保存到：

```text
runs/grasp_headless/*.tar.gz
```

解压后重点看：

- `frame_*.jpg`：带 YOLO 框的关键帧。
- `pick.log`：完整抓取日志。
- `pick_tail.log`：最后 160 行日志。
- `detections.csv`：每一帧检测到的类别、置信度、中心 `cx`、面积 `area`。
- `session.log`：相机是否启动、帧数、检测行数、最终状态。

## 调参顺序

先只调这几个参数：

```powershell
python tools\headless_grasp_trial.py --target-class grass --target-depth 0.30
python tools\headless_grasp_trial.py --target-class grass --target-depth 0.34
```

如果总是左右偏：

```powershell
python tools\headless_grasp_trial.py --target-class grass --center 0.48
python tools\headless_grasp_trial.py --target-class grass --center 0.52
```

如果动作太慢/太快：

```powershell
python tools\headless_grasp_trial.py --target-class grass --max-linear-speed 0.045 --max-angular-speed 0.16
python tools\headless_grasp_trial.py --target-class grass --max-linear-speed 0.025 --max-angular-speed 0.10
```

如果夹取过程中来不及微调：

```powershell
python tools\headless_grasp_trial.py --target-class grass --settle-before 1.0 --settle-after 0.8
```

## 判断问题

- `frame_count=0`：相机链路没出图，先修相机。
- `detection_rows=0`：YOLO 没检测到，检查模型类别或置信度。
- 有框但 `FAILSAFE`：看 `pick_tail.log` 里最后的 `distance_source/value/target/error`。
- 抓偏左/右：调 `--center`。
- 早下抓/晚下抓：优先调 `--target-depth`，面积先不要动。
