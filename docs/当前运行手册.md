## 2. 实机前检查

机器人开机后，先确认：

1. 电脑已切到机器人热点。
2. SSH 能连到机器人。
3. Docker 容器 `MentorPi` 存在。
4. 模型文件已在容器内：

```text
/home/ubuntu/ros2_ws/src/yolov11_detect/models/tongji.xml
/home/ubuntu/ros2_ws/src/yolov11_detect/models/tongji.bin
```

5. ROS2 包已构建：

```bash
cd /home/ubuntu/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 pkg prefix competition_pick_place
```

## 3. 推荐：headless 单次抓取

本地 PowerShell：

```powershell
python tools\headless_grasp_trial.py --target-class grass
```

其他类别：

```powershell
python tools\headless_grasp_trial.py --target-class gray
python tools\headless_grasp_trial.py --target-class yellow
python tools\headless_grasp_trial.py --target-class blue
```

输出：

```text
runs/grasp_headless/<时间>_<类别>.tar.gz
```

解压后看：

```text
session.log       本次会话状态
pick_tail.log     最后 160 行抓取日志
pick.log          完整日志
detections.csv    检测框序列
frame_*.jpg       带框关键帧
```

## 4. 常用调参

### 抓得太远或太近

优先调深度目标：

```powershell
python tools\headless_grasp_trial.py --target-class grass --target-depth 0.30
python tools\headless_grasp_trial.py --target-class grass --target-depth 0.34
```

### 左右偏

调目标中心：

```powershell
python tools\headless_grasp_trial.py --target-class grass --center 0.48
python tools\headless_grasp_trial.py --target-class grass --center 0.52
```

### 下探时来不及微调

增加 settle 窗口：

```powershell
python tools\headless_grasp_trial.py --target-class grass --settle-before 1.0 --settle-after 0.8
```

### 速度太快或太慢

```powershell
python tools\headless_grasp_trial.py --target-class grass --max-linear-speed 0.025 --max-angular-speed 0.10
python tools\headless_grasp_trial.py --target-class grass --max-linear-speed 0.045 --max-angular-speed 0.16
```

## 6. 结果判断

看 `session.log`：

```text
frame_count=0
```

说明相机没有出图，先修相机链路。

```text
detection_rows=0
```

说明 YOLO 没有检测输出，检查模型名、类别顺序和置信度。

```text
run_status=done
```

说明流程跑到 DONE，但不一定代表实际夹住，需要看夹爪反馈日志和关键帧。

```text
run_status=failsafe
```

看 `pick_tail.log` 最后的 `distance_source`、`value`、`target`、`error`、`cmd`。

## 7. 日志关键词

优先搜索：

```text
distance_source=depth
distance_source=area
aligned
grasp check success
grasp check empty
FAILSAFE
DONE
```

含义：

- `distance_source=depth`：正在用深度估距。
- `distance_source=area`：深度不可用，回退到面积估距。
- `grasp check empty`：夹爪反馈判断为空夹，会重试。
- `no fresh gripper feedback`：没有新夹爪反馈，代码会保守认为成功，避免无限重试。

## 8. 完整导航流程

当前 `competition_waypoints.yaml` 仍是占位零坐标。完整流程前必须标定：

```text
material_standoff_pose
place_standoff_pose
return_pose
```

未标定前只建议运行：

```text
use_nav:=false
stop_after_pick:=true
```

不要直接跑完整导航、放置和返航。
